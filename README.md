# דבורה ומאיר — מדריך חומרי ארכיון לעורך

אתר RTL סטטי בפורמט מדריך מייקל לוין v2. הוא מאגד מקורות ארכיון ציבוריים ומפת בקשות לאלבומי משפחה — ולא את חומרי הצילום של הראיון.

## עקרונות

- לכל מקור: מה רואים/שומעים, למה הוא רלוונטי לסרט, זכויות, אימות והצעד הבא.
- מקורות היסטוריים מספקים הקשר; אלבומי המשפחה אמורים לחבר את ההקשר לדבורה ומאיר עצמם.
- כרטיסי `DM-F` הם blueprints לאיסוף, לא קבצים קיימים.
- אין מדיה מוגנת בתוך ה־repository.
- האתר `noindex,nofollow,noarchive` אך repository/Page ציבוריים טכנית.

## בנייה

```bash
npm run check
```

ה־generator קורא את מחקר המקורות המקומי ומפיק `data/archive.json`; GitHub Actions בודק את התוצר הציבורי בלי להזדקק לקובץ המחקר הפרטי.
